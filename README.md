# exercícios-python
Este repositório contém os exercícios do curso de Python do professor Gustavo Guanabara do [Curso em Vídeo](cursoemvideo.com).
Algumas respostas são personalizadas a meu gosto, alguma usa do recursos do Python outros aplicando lógica para usar em qualquer linguagem.
Alguns exercícios contêm uso de bibliotecas e comandos não ensinados nas aulas de python, como o parâmetro **start** que é utilizado no enumerate,o exercício 95 tem destaque em validação de dados.
Utilizou-se blocos de **while True** com try-except.
